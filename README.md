#  Python Mini Calculator

#  Project Description
Python Mini Calculator is a simple command-line application developed using Python. It performs basic arithmetic operations based on the user's choice.

This project is designed to understand Python fundamentals and gain practical programming experience.

#  Features
- Addition
- Subtraction
- Multiplication
- Division
- User-friendly menu
- Takes input from the user
- Displays the calculated result

#  Technologies Used
- **Programming Language:** Python
- **Platform:** Visual Studio Code / Python IDLE

#  How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python file.

```bash
python calculator.py
```

4. Choose an arithmetic operation.
5. Enter the required numbers.
6. View the result.
